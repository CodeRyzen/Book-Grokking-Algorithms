# Grokking Algorithms Study Repository
## Overview
This repository is a personal study companion for Grokking Algorithms by Aditya Bhargava, an illustrated and beginner-friendly book that demystifies complex algorithms. Here, I organize my notes, exercise solutions, and code implementations to deepen my understanding of algorithms and track my progress.
Repository Structure
## The repository is divided into three main folders:
### conspectuses/

Contains detailed summaries and notes for each chapter of Grokking Algorithms.
Covers key concepts like binary search, recursion, sorting, graph algorithms, and more.
Written in a concise, easy-to-understand format to reinforce learning.

### exercises/

Includes my solutions to the exercises and problems from the book.
Demonstrates practical applications of algorithms to solidify understanding.
Organized by chapter or topic for easy navigation.

### source_code/

Houses Python implementations of algorithms and examples from the book.
Features clean, commented code for algorithms like quicksort, breadth-first search, and dynamic programming.
Designed to be run directly with minimal setup.

## About Grokking Algorithms
Grokking Algorithms by Aditya Bhargava is a highly visual guide to understanding algorithms. It uses simple analogies, diagrams, and examples to explain concepts like Big O notation, greedy algorithms, and more. This repository reflects my journey through the book, capturing insights and practical work.
## Usage

Explore Notes: Start with the conspectuses/ folder to review chapter summaries and key takeaways.
Try Exercises: Visit the exercises/ folder to see my solutions or attempt the problems yourself.
Run Code: Check out the source_code/ folder to experiment with algorithm implementations (Python 3.x required).
Adapt and Contribute: Fork the repo, add your own notes, or tweak the code to suit your needs.

## Prerequisites

Basic knowledge of Python programming.
Python 3.x installed for running code in the source_code/ folder.
A copy of Grokking Algorithms by Aditya Bhargava (recommended for context).
